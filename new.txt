Description
-----------
A complete Node.js backend system with Firebase integration featuring user
authentication, file uploads to Firebase Cloud Storage, and Firestore
database management.

Features
--------
- User Authentication (Signup/Login) with Firebase Auth
- File Upload to Firebase Cloud Storage
- File Management: list, view, delete uploaded files
- JWT token-based secure API
- Firestore database for user and file metadata
- RESTful API endpoints
- Included HTML test client

Key API Endpoints
------------------
Auth:
- POST /api/auth/signup
- POST /api/auth/login

Files (Authenticated):
- POST   /api/upload
- GET    /api/files
- DELETE /api/files/:fileId

Misc:
- GET /api/health

Firestore Collections
----------------------
users/  { email, displayName, createdAt, uploads }
files/  { userId, fileName, storagePath, fileSize, mimeType, publicUrl, uploadedAt }
